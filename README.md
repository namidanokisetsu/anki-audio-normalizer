# Audio Normalizer for Anki

Audio collected from different sources or generated by different text-to-speech
services often plays at inconsistent volumes. Audio Normalizer evens out those
differences so you do not have to adjust the volume while reviewing cards.

Processing happens on your computer. Card text and audio are never uploaded.
The add-on does not download or install executables.

## Features

- Normalize audio across a deck
- Narrow the scope with an Anki search
- Process selected notes from the Browser
- Preview the result before changing anything
- Run manually or automatically
- Restore references to retained originals
- Resume interrupted work and skip completed files

## Compatibility

Version 0.9.0 is a beta for Anki 25.09.4 or newer. It has been tested through
Anki 26.05; newer Anki releases are allowed but may not yet have been verified.
Supported platforms are:

- Windows x64
- macOS on Apple silicon or Intel
- Linux x64 or ARM64

The add-on requires a current FFmpeg installation containing the `loudnorm`,
`libmp3lame`, `libopus`, `aac`, `flac`, and `pcm_s16le` components. It uses
FFmpeg found on `PATH`; common Homebrew locations are also checked on macOS.
Set `ANKI_AUDIO_NORMALIZER_FFMPEG` to an explicit executable path if needed.

Install FFmpeg with a maintained package source, then restart Anki:

- Windows: `winget install --id Gyan.FFmpeg`
- macOS: `brew install ffmpeg`
- Debian/Ubuntu: `sudo apt install ffmpeg`

Other Linux distributions should use their normal package manager. Keep FFmpeg
updated because it parses media files. See [third-party notices](THIRD_PARTY_NOTICES.md).

## Install

For the published version, use the add-on code shown on its AnkiWeb page in
Anki's **Tools → Add-ons → Get Add-ons…** dialog, then restart Anki.

For a development build, follow **Development** below and install
`dist/audio-normalizer.ankiaddon` with Anki's **Install from file…** action.

## Use

1. Open **Tools → Normalize Card Audio…**.
2. Choose a deck and, if needed, narrow it with an Anki search.
3. Choose **MP3** or **Keep source extension**.
4. Select **Preview**, then **Save and normalize**.

Parent decks include their subdecks. Each matching audio file is processed once,
even when several cards use it.

To target selected notes or the current Browser search, open Audio Normalizer
from the Browser's **Notes** or context menu.

Automatic runs can start after Anki opens, after a sync, or after notes change.
They are disabled by default.

## Output options

- **MP3** offers the widest Anki playback compatibility.
- **Keep source extension** avoids changing the filename extension, but adjusted
  compressed audio is still re-encoded. Unsupported formats are skipped.

## Restore and safety

Normalization creates new media files and updates the cards to use them. The
original files are not overwritten or deleted.

**Restore** switches eligible cards back to their recorded originals and turns
off automatic runs. It skips originals that are missing or cannot be identified
safely. Generated files remain in the media collection and therefore use
additional local and AnkiWeb media storage.

Before a large run, export an all-decks `.colpkg` with **Include media**. Do not
use **Check Media → Delete Unused** until you have verified the result, because
retained originals may appear unused.

## Limitations

- The add-on adjusts the overall volume of each file; it cannot fix volume
  changes within a recording.
- Some very quiet, silent, damaged, unsupported, or unusually large files may be
  skipped and reported.
- It does not remove noise, trim silence, or change playback speed or pitch.

## Development

Run the tests and build the add-on:

```bash
python -m unittest discover -s tests -v
python tools/build_addon.py
```

Build the optional demo deck:

```bash
python -m pip install -r requirements.txt
python tools/build_demo_deck.py
```

Artifacts are written to `dist/`.
