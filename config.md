# Configuration

Open **Tools → Normalize Card Audio…**. Configure and run manual normalization
at the top. Optional search and loudness controls are under **More settings**.
The bottom **Automatic normalization** section can run the same configuration
after startup, sync, or note changes. Automatic runs use compact Anki
notifications by default; **Run feedback** can switch them to the detailed log
window.

Direct JSON editing is not recommended. Settings are stored independently for
each Anki profile.

The add-on uses an existing FFmpeg installation and never downloads an
executable. If FFmpeg is not detected, follow the platform instructions in the
README, restart Anki, and try again.
