# Third-party software

Audio Normalizer invokes an FFmpeg executable installed and maintained by the
user or operating system. FFmpeg is not included with this add-on and is never
downloaded by it.

FFmpeg is a separate project with licensing determined by how a particular
binary was built. Most FFmpeg code is available under LGPL 2.1 or later, while
builds made with GPL components are available under GPL 2 or later. Consult the
license information supplied by your FFmpeg distributor and the upstream
project:

- https://ffmpeg.org/legal.html
- https://ffmpeg.org/download.html

The Audio Normalizer source code remains licensed under the MIT License in
`LICENSE`.
